# Wordbook（单词本）

一款**离线优先**的语境化英语词汇学习 Android 应用，主要面向考研英语备考者。

## 为什么选择 Wordbook？

传统背单词软件有两个通病：**单词与语境割裂**（背诵孤立的词汇表，缺乏真实文本的关联支撑）和**强网络依赖**（在线查词在地铁、图书馆等场景不可靠）。

Wordbook 的解决思路是让用户将任意英文文章粘贴进应用，直接从中选取陌生单词和长难句纳入学习计划，实现"从阅读中来，到记忆中去"的语境化学习闭环。内置约 5500 词的离线英汉词典，核心查词功能无需网络即可完成。

## 主要功能

- **从文章提取单词**：粘贴英文文章，自动分词，点击选择需要学习的单词
- **长难句语法分析**：长按拖选句子，DeepSeek AI 自动分析从句结构、标注语法角色、生成树状图
- **AI 智能翻译**：DeepSeek AI 返回单词的词性 + 中文释义 + 原句定位 + 句子翻译
- **三级翻译回退**：DeepSeek AI → 本地词典（~5500 词）→ 占位提示，平滑离线降级
- **FSRS 间隔复习**：基于 FSRS v5 算法的抽认卡复习系统，科学安排复习间隔，单词和长句独立调度
- **卡片翻转 + 滑动**：点击翻卡查看释义，左右滑动切换上一张/下一张
- **文章组管理**：将单词按文章来源分组，复习时原文高亮当前单词位置和长句
- **长按删除**：单词、文章、长句均支持长按删除，带确认弹窗
- **句子结构着色**：9 种语法类型分色标注，含颜色图例，移动端点触查看类型/角色
- **纯本地存储**：所有数据存储在 localStorage，无服务端、无账号、无隐私顾虑

### 页面流转

```
首页(文章列表)
  ├── [底部导航] → 单词页面 / 长句页面 / 设置页面
  ├── [添加文章] → 粘贴文章 → 处理文章 → 点击选词 / 长按拖选长句 → 保存
  ├── [点击文章卡片] → 文章详情页 (闪卡 + 原文高亮)
  ├── [点击单词卡片] → 单词详情页 (例句展示)
  ├── [点击长句卡片] → 长句详情页 (语法分析)
  ├── [开始复习] → 单词复习 / 长句复习 → 评分 → 完成统计
  └── [长按] → 确认删除
```

## 技术架构

```
┌──────────────────────────┐
│  Android WebView 壳       │   Kotlin / MainActivity
│  加载 assets/index.html  │
├──────────────────────────┤
│  单页 Web 应用（SPA）     │
│  ├─ app.js       核心逻辑 │   ~2900 行，状态管理、CRUD、FSRS复习、语法标注
│  ├─ dictionary.js 离线词库 │   ~5500 考研英语词汇
│  ├─ translator.js 翻译模块 │   DeepSeek Chat API + 本地词典回退 + 长句分析
│  ├─ fsrs.js       复习算法 │   FSRS v5 间隔重复调度
│  └─ styles.css    样式    │   OKLCH 色彩空间、CSS 变量、过渡动画
└──────────────────────────┘
```

- **Android 层**：极薄封装，仅 `ComponentActivity` + `WebView`
- **Web 层**：原生 JavaScript SPA，不依赖任何前端框架
- **数据持久化**：`localStorage`（键：`wordbook`、`articles`、`sentencebook`、`deepseekApiKey`）
- **翻译服务**：DeepSeek AI Chat API，通过 system prompt 约束返回结构化 JSON
- **复习算法**：FSRS v5（Free Spaced Repetition Scheduler），基于遗忘曲线自动调度
- **色彩系统**：OKLCH 色彩空间，感知均匀，主题色全局可控

## 核心逻辑流

```
用户粘贴文章 ──→ 正则分词（单词 / 标点 / 空白）
       │
       ├──→ 点击选中单词 ──→ 批量翻译 ──→ 三级回退：
       │                         ├─ DeepSeek AI（词性+释义+原句+翻译）
       │                         ├─ 本地词典 O(1) 查找（~5500 词）
       │                         └─ 占位提示文本
       │
       ├──→ 长按拖选长句 ──→ AI 语法分析 ──→ 从句分段+角色标注+树状图
       │
       ▼
保存到文章组 ──→ FSRS 间隔复习：
                    ├─ 单词复习：卡片翻转 + 左右滑动
                    ├─ 长句复习：语法结构着色展示
                    ├─ 评分 (忘记/困难/正常) → FSRS 自动调度
                    ├─ 原文高亮（单词蓝底 + 长句紫线下划线）
                    └─ 本地 localStorage 持久化
```

## v1.5 更新 (2026-08-10)

### 性能优化
- **并行翻译**：单词翻译与长句分析从串行改为 `Promise.all` 并行执行，保存耗时降低约 5 倍
- **批量翻译并行化**：`translateBatch()` 从串行 `for-of` 改为 `Promise.all` 并发
- **保存进度反馈**：按钮文案实时显示翻译进度（如"正在翻译 (3/6)..."）

### 长句语法分析
- 新增长难句 DeepSeek AI 语法分析功能
- 9 种从句类型自动识别：主句、宾语从句、定语从句、让步状语、条件状语、不定式目的、强调句、嵌套从句、其他从句
- 语法角色标注：主语(S)、谓语(V)、宾语(O)、定语(Attr)、状语(Adv) 等
- 树状图结构展示 + 逐层拆解
- 9 种类型分色标注，含颜色图例，移动端点击片段查看类型/角色

### 色彩系统重构
- 主题色从 Material Green 迁移为蓝色系，统一使用 OKLCH 色彩空间
- CSS 变量驱动全局配色（`--primary-color`、`--accent-color` 等）
- 长句划线统一为淡紫色（同"忘记"按钮）
- 目标单词高亮统一为半透明蓝底 + 蓝紫色字

### FSRS 间隔复习
- 引入 FSRS v5 间隔重复调度算法
- 单词和长句独立复习队列，自动按遗忘曲线调度
- 复习完成统计面板（已掌握/模糊/忘记计数）
- 支持"再复习忘记的"和"复习全部"

### Bug 修复
- **中文乱码**：`stripHtml()` 不再对纯文本误用 DOMParser 解析，避免 `<>` 符号导致中文丢失
- **仅选长句无法保存**：修复必须选单词才能保存的限制，现在单词和长句至少选其一即可
- **划线颜色轮换移除**：长句划线从 5 色轮换改为固定淡紫色

## 快速开始

### 构建 Android 应用

```bash
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/`。

### 在浏览器中开发调试

DeepSeek API 支持浏览器端 CORS 请求，直接在浏览器中打开 `index.html` 即可调试。

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```
